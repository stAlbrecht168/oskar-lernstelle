PDF-Text wird lokal ausgelesen; Bilder werden per Texterkennung im Browser verarbeitet. Dafür lädt der Browser externe Open-Source-Bibliotheken und Sprachmodelle. Die App überträgt dabei keine Inhalte an einen eigenen Server. Lokal erzeugte Karten kommen nur aus erkannten Begriff-Erklärung-Paaren. Über einen optionalen geschützten KI-Dienst sind zusätzliche Vorschläge möglich, die an dessen Anbieter übertragen und ebenfalls geprüft werden müssen. Prüfe OCR-Fehler und Fachinhalte vor der Freigabe.

Datenschutz & Grenzen

GitHub Pages ist öffentlich, aber Schulunterlagen, Entwürfe und Ergebnisse bleiben im lokalen Browser-Speicher. Dieser Browser kann von anderen Personen auf demselben Gerät eingesehen werden. Die Materialbibliothek ist nicht durch Anmeldung geschützt. Keine Daten werden geräteübergreifend synchronisiert. Original-Dateien werden nicht im Git-Repository gespeichert.

Daten sichern / auf ein weiteres Gerät übertragen

Die Backup-Datei enthält auch Noten, Arbeiten, Lernanalysen und Fortschritte. Bewahre sie privat auf.

Spätere Ausbaustufe

Der KI-Dienst kann über GitHub Actions nach dem Hinterlegen der Zugangsdaten bereitgestellt werden. Foto-/PDF-Qualitätsprüfung und echte geräteübergreifende Synchronisation fehlen.
